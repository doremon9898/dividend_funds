# DivFund Tracker 💰

แอปเว็บสำหรับบันทึกและติดตาม **กองทุนหุ้นปันผล** ดูว่าแต่ละกองได้กำไรหรือขาดทุนเท่าไหร่ ได้ปันผลเดือนละกี่บาท และวิเคราะห์ว่าควรถือต่อหรือขาย

สร้างด้วย **Flask** (ไฟล์เดียว `app.py`) + **Tailwind CSS (CDN)** + **Chart.js** และเก็บข้อมูลด้วย **SQLite**

---

## 📦 สิ่งที่ต้องมี

- Python 3.9 ขึ้นไป
- อินเทอร์เน็ต (ต้องใช้โหลด Tailwind, Chart.js และฟอนต์จาก CDN)

## 🚀 วิธีติดตั้งและรัน

1. ติดตั้ง Flask

   ```bash
   pip install flask
   ```

2. รันแอป

   ```bash
   python app.py
   ```

3. เปิดเบราว์เซอร์ไปที่ **http://127.0.0.1:5000**

> 💡 ถ้าพอร์ต 5000 มีโปรแกรมอื่นใช้อยู่ ให้กำหนดพอร์ตเองได้ เช่นใน PowerShell `$env:PORT=8000; python app.py`

ตอนรันครั้งแรก ระบบจะสร้างไฟล์ฐานข้อมูล `dividend_funds.db` ไว้ในโฟลเดอร์เดียวกันให้อัตโนมัติ

## 📝 วิธีเพิ่มกองทุน

กด **"+ เพิ่มกองทุน"** แล้วกรอกข้อมูล 4 ส่วน (ดูข้อมูลได้จาก Fund Fact Sheet และใบยืนยันการซื้อ)

1. **ข้อมูลกองทุน** – รหัสและชื่อกองทุน (ต้องกรอก), บลจ., หมวดสินทรัพย์, ระดับความเสี่ยง 1–8
2. **การถือครอง**
   - จำนวนหน่วยที่ถือ
   - ต้นทุนเฉลี่ย (บาท/หน่วย)
   - NAV ปัจจุบัน (ถ้าเว้นว่าง ระบบจะใช้ค่าเดียวกับต้นทุน)
3. **นโยบายปันผล**
   - **ปันผลต่อหน่วยต่อปี** – รวมทุกงวดใน 12 เดือนล่าสุด เช่น จ่ายงวดละ 0.30 ปีละ 2 ครั้ง ให้กรอก `0.60`
   - **ค่าธรรมเนียมรวม (% ต่อปี)** – ค่า TER จาก Fact Sheet
   - **เดือนที่จ่ายปันผล** – กดเลือกเดือนได้หลายเดือน ระบบใช้ข้อมูลนี้ทำปฏิทินปันผล
4. **บันทึกเพิ่มเติม** – เหตุผลที่ลงทุน หรือสิ่งที่ต้องติดตาม

ระหว่างกรอก ระบบจะแสดง **ต้นทุนรวม / กำไร-ขาดทุน / ปันผลต่อเดือน** ให้ดูทันที

## 📖 การใช้งานแต่ละหน้า

### 🏠 แดชบอร์ด
ภาพรวมของทั้งพอร์ต
- มูลค่าพอร์ต, ต้นทุนรวม, กำไร/ขาดทุน (บาทและ %)
- **ปันผลเฉลี่ยต่อเดือน** (หลังหักภาษี 10%), Yield on Cost, Yield ปัจจุบัน
- ปันผลที่รับแล้วทั้งหมด, ภาษีที่ถูกหัก, ผลตอบแทนรวมปันผล, คะแนนสุขภาพพอร์ต
- กราฟปันผล 12 เดือน, สัดส่วนพอร์ต, กำไร/ขาดทุนแต่ละกอง
- รายการ **ปันผลที่กำลังจะเข้า** และข้อสังเกตของพอร์ต
- กดที่แถวของกองทุนในตารางเพื่อเปิดหน้ารายละเอียด

### 📁 กองทุนของฉัน
แสดงทุกกองเป็นการ์ด
- **ค้นหา** ด้วยรหัส ชื่อ หรือ บลจ.
- **กรอง** ตามคำแนะนำ (สะสมเพิ่ม / ถือต่อ / ฯลฯ)
- **เรียง** ตามมูลค่า, % กำไร, Yield, ปันผลต่อเดือน หรือคะแนน
- ปุ่ม **CSV** ดาวน์โหลดข้อมูลไปเปิดใน Excel

### 🔍 หน้ารายละเอียดกองทุน
ส่วนซ้ายเป็นตัวเลขสรุป กราฟปันผลต่อหน่วยย้อนหลัง ประวัติปันผล และประวัติซื้อขาย

ส่วนขวามีเครื่องมือดังนี้

**ผลวิเคราะห์** – คะแนน 0–100, คำแนะนำ และเหตุผลแต่ละข้อพร้อมคะแนนบวก/ลบ

**แท็บ ซื้อ/ขาย**
- เลือก **ซื้อเพิ่ม** หรือ **ขาย**
- กรอก NAV ที่ซื้อขาย แล้วกรอก **จำนวนเงิน (บาท)** หรือ **จำนวนหน่วย** อย่างใดอย่างหนึ่ง
- ซื้อเพิ่ม → ระบบคำนวณ **ต้นทุนเฉลี่ยใหม่** ให้อัตโนมัติ
- ขาย → ระบบคำนวณ **กำไร/ขาดทุนที่ขายได้จริง** (ต้นทุนเฉลี่ยเท่าเดิม)
- ติ๊ก "อัปเดต NAV ปัจจุบันด้วยราคานี้" ถ้าต้องการให้ NAV ปัจจุบันเปลี่ยนตาม

**แท็บ บันทึกปันผล**
- ระบบใส่ปันผลต่อหน่วยต่องวดและจำนวนหน่วยที่ถือให้ก่อน แก้ไขได้
- ติ๊ก/ไม่ติ๊ก "หักภาษี ณ ที่จ่าย 10%" ได้

**แท็บ NAV** – อัปเดต NAV ล่าสุดของกองนี้

**เครื่องคิดเลข What-if** (ทดลองตัวเลขเท่านั้น ไม่บันทึกลงระบบ)
- *ถ้าซื้อเพิ่ม X บาท* → ได้กี่หน่วย ต้นทุนเฉลี่ยใหม่เท่าไหร่ ปันผลต่อเดือนใหม่เท่าไหร่
- *ถ้า NAV เปลี่ยนเป็น...* → เลื่อนแถบดูกำไร/ขาดทุนและ Yield ที่จะได้

ปุ่ม **แก้ไข** ใช้ปรับข้อมูลกองทุน ส่วนปุ่ม **ลบ** จะลบกองทุนพร้อมประวัติทั้งหมด

> ⚠️ การแก้จำนวนหน่วยหรือต้นทุนในหน้าแก้ไข **จะไม่สร้างรายการซื้อขาย** ถ้าซื้อเพิ่มหรือขายจริง ให้ใช้แท็บ ซื้อ/ขาย แทน

### ✨ วิเคราะห์ & คำแนะนำ
- **คะแนนสุขภาพพอร์ต** – ค่าเฉลี่ยของคะแนนทุกกอง ถ่วงน้ำหนักตามมูลค่า
- จำนวนกองในแต่ละกลุ่มคำแนะนำ
- ข้อสังเกตของพอร์ต เช่น กระจุกตัวเกินไป ปันผลลดลง หรือค่าธรรมเนียมสูง
- รายการกองทุนเรียงตามคะแนน กดเพื่อดูเหตุผลแต่ละข้อ

### 📅 ปันผล & ปฏิทิน
- **ปฏิทินปันผลคาดการณ์ ม.ค.–ธ.ค.** แยกสีตามกองทุน (เดือนปัจจุบันจะไฮไลต์ไว้)
- กราฟปันผลที่ได้รับจริง 12 เดือน และยอดรวมรายปี (พ.ศ.)
- ฟอร์มบันทึกปันผล (เลือกกองแล้วระบบเติมข้อมูลให้)
- ประวัติปันผลทั้งหมด ลบรายการได้ที่ไอคอนถังขยะ

### 🔄 อัปเดต NAV
กรอก NAV ใหม่ของทุกกองในหน้าเดียว ระบบแสดง % ที่เปลี่ยน และกำไร/ขาดทุนใหม่ก่อนกดบันทึก
แนะนำให้อัปเดตสัปดาห์ละครั้ง หรือก่อนดูผลวิเคราะห์

### 🎯 วางแผนเป้าหมาย
ตั้งเป้ารายได้จากปันผลแล้วจำลองการลงทุน
- กรอก **เป้าหมายปันผลสุทธิต่อเดือน**, มูลค่าพอร์ตเริ่มต้น, อัตราปันผล, เงิน DCA ต่อเดือน และการเติบโตของ NAV
- เลือกว่าจะ **นำปันผลไปลงทุนต่อ (ทบต้น)** หรือไม่
- ผลลัพธ์: **เงินลงทุนที่ต้องมี**, ยังขาดอีกเท่าไหร่, **ถึงเป้าในอีกกี่ปี**, กราฟ และตารางรายปี

## 🧠 เกณฑ์การวิเคราะห์

ทุกกองเริ่มที่ **50 คะแนน** แล้วบวก/ลบตามปัจจัยด้านล่าง (สูงสุด 100 ต่ำสุด 0)

| ปัจจัย | เงื่อนไข | คะแนน |
|---|---|---|
| อัตราปันผลปัจจุบัน | ≥ 6% / ≥ 4% / ≥ 2% / ต่ำกว่า 2% / ไม่จ่าย | +15 / +8 / −3 / −12 / −20 |
| กำไร/ขาดทุน | กำไร ≥ 30% / เป็นบวก / ขาดทุนไม่เกิน 15% / ขาดทุนมากกว่า 15% | +5 / +5 / −3 / −10 |
| ผลตอบแทนรวมปันผล | ราคาขาดทุน แต่รวมปันผลแล้วยังเป็นบวก | +8 |
| แนวโน้มปันผล | งวดล่าสุดเทียบงวดก่อน: เพิ่ม > 5% / คงที่ / ลด > 5% | +10 / +3 / −15 |
| ค่าธรรมเนียม | > 1.5% / ≤ 0.8% | −8 / +4 |
| สัดส่วนในพอร์ต | > 40% / > 25% | −10 / −4 |
| คืนทุนด้วยปันผล | ต้องใช้เกิน 5 ปี / ไม่เกิน 5 ปี | −8 / +2 |
| Yield on Cost | สูงกว่ายีลด์ปัจจุบันเกิน 1% | +3 |

**คำแนะนำตามคะแนน**

| คำแนะนำ | เงื่อนไข |
|---|---|
| ⬆ **สะสมเพิ่ม** | คะแนน ≥ 72 |
| ● **ถือต่อ** | คะแนน 52–71 |
| ◎ **ขายทำกำไรบางส่วน** | กำไร ≥ 30% แต่ Yield ปัจจุบัน < 4% (เช็กเงื่อนไขนี้ก่อน) |
| ⚠ **เฝ้าระวัง** | คะแนน 38–51 |
| ⬇ **พิจารณาขาย** | คะแนน < 38 |

ปรับเกณฑ์ได้ที่ฟังก์ชัน `analyze_fund()` ใน `app.py`

## 🧮 สูตรที่ใช้คำนวณ

| ค่า | สูตร |
|---|---|
| ต้นทุนรวม | หน่วย × ต้นทุนเฉลี่ย |
| มูลค่าปัจจุบัน | หน่วย × NAV |
| กำไร/ขาดทุน | มูลค่าปัจจุบัน − ต้นทุนรวม |
| ปันผลต่อปี | หน่วย × ปันผลต่อหน่วยต่อปี |
| ปันผลสุทธิต่อเดือน | ปันผลต่อปี × (1 − 10%) ÷ 12 |
| Yield on Cost | ปันผลต่อหน่วยต่อปี ÷ ต้นทุนเฉลี่ย |
| Yield ปัจจุบัน | ปันผลต่อหน่วยต่อปี ÷ NAV |
| ต้นทุนเฉลี่ยใหม่ (ซื้อเพิ่ม) | (หน่วยเดิม × ต้นทุนเดิม + หน่วยใหม่ × NAV) ÷ หน่วยรวม |
| กำไรที่ขายได้จริง | หน่วยที่ขาย × (NAV ที่ขาย − ต้นทุนเฉลี่ย) |
| ผลตอบแทนรวม | กำไร/ขาดทุน + ปันผลที่รับแล้ว + กำไรที่ขายได้จริง |

## 🗂 โครงสร้างโปรเจค

```
week_2/
├── app.py              # โค้ดทั้งหมด (routes, การวิเคราะห์, templates)
├── dividend_funds.db   # ฐานข้อมูล SQLite (สร้างอัตโนมัติ)
└── README.md
```

ใน `app.py` มีตาราง 3 ตาราง

- `funds` – ข้อมูลกองทุนและการถือครอง
- `dividends` – ประวัติปันผลที่ได้รับ
- `transactions` – ประวัติซื้อ/ขาย

## 💾 สำรองและย้ายข้อมูล

- **สำรองข้อมูล:** copy ไฟล์ `dividend_funds.db` เก็บไว้
- **เริ่มใหม่:** ปิดแอปแล้วลบไฟล์ `dividend_funds.db` หรือกด "ล้างข้อมูลทั้งหมด"
- **Export:** กด "Export CSV" ที่เมนูซ้าย ไฟล์เปิดใน Excel แล้วภาษาไทยไม่เพี้ยน

## ⚙️ การตั้งค่า

| ตั้งค่า | วิธี |
|---|---|
| อัตราภาษีปันผล | แก้ `TAX_RATE = 0.10` ใน `app.py` |
| หมวดสินทรัพย์ | แก้รายการ `CATEGORIES` |
| พอร์ต | ตัวแปรสภาพแวดล้อม `PORT` |
| Secret key | ตัวแปรสภาพแวดล้อม `SECRET_KEY` (ควรตั้งถ้าเปิดให้คนอื่นใช้) |

> แอปรันด้วย `debug=True` เหมาะสำหรับใช้ในเครื่องตัวเอง ถ้าจะเปิดบนเซิร์ฟเวอร์ ควรปิด debug และใช้ WSGI server เช่น `waitress` หรือ `gunicorn`

## ⚠️ ข้อควรทราบ

- ผลวิเคราะห์มาจาก **เกณฑ์อัตโนมัติ** ใช้ช่วยตัดสินใจเบื้องต้นเท่านั้น **ไม่ใช่คำแนะนำการลงทุน** ควรอ่านหนังสือชี้ชวนก่อนตัดสินใจ
- ปันผลคาดการณ์คิดจากปันผลต่อหน่วยที่กรอกไว้ ปันผลจริงอาจต่างไปตามผลประกอบการของกองทุน
- ภาษีปันผลกองทุนถูกหัก ณ ที่จ่าย 10% ถ้านำไปรวมยื่นภาษีปลายปี ใช้ภาษีที่ถูกหักเป็นเครดิตภาษีได้ (ดูยอดได้ที่หน้าแดชบอร์ด)
- ระบบไม่ได้ดึง NAV อัตโนมัติ ต้องอัปเดตเองที่หน้า **อัปเดต NAV**
